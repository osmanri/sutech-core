# Проверка прошивки на компьютере

`test_firmware.cpp` компилирует `../arduino_relay_pump/arduino_relay_pump.ino` обычным g++ вместе с заглушками (`Arduino.h`, `EEPROM.h`). Тест проверяет сигнал реле при старте, ручной остановке, достижении дозы и пропадании импульсов. Также проверяются пределы команды, защита при низком уровне воды, отклонение повторного запуска и сброса счётчика во время подачи, сохранение калибровки и обработка некорректных значений.

```bash
cd firmware/host_test
g++ -std=c++17 -Wall -I. test_firmware.cpp -o test_firmware && ./test_firmware
```

Тест подставляет показания датчиков, импульсы и время. Сборка для микроконтроллера выполняется отдельно в Arduino IDE или Arduino CLI. Перечень измерений для собранного стенда приведён в [плане проверки](../../docs/AI_HARDWARE_VALIDATION.md).
