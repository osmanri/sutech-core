# Проверка прошивки на компьютере

`test_firmware.cpp` компилирует `../arduino_relay_pump/arduino_relay_pump.ino` обычным g++ вместе с заглушками (`Arduino.h`, `EEPROM.h`) и проверяет логику насоса и расходомера: доза по объёму, остановка по таймеру, калибровка, защита от сухого хода, сохранение в EEPROM.

```bash
cd firmware/host_test
g++ -std=c++17 -Wall -I. test_firmware.cpp -o test_firmware && ./test_firmware
```

Это проверка логики, а не железа: датчики в заглушках возвращают постоянные значения, импульсы расходомера подаются из теста. Прошивку для платы по-прежнему собирает Arduino IDE.
