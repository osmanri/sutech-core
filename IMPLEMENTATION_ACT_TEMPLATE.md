## IV. МЕТОДОЛОГИЯ ИСПЫТАНИЯ

### 4.1 Описание программного комплекса «Su-Tech»

Программный комплекс **«Su-Tech»** представляет собой мобильную Telegram-платформу (Mini App) для расчёта нормы орошения сельскохозяйственных угодий. Система получает GPS-координаты поля непосредственно с мобильного устройства пользователя и автоматически запрашивает метеорологические данные через открытый спутниковый API **Open-Meteo** (ERA5/GFS/ICON реанализ, пространственное разрешение ~2 км, обновление каждые 15 мин).

Расчёт нормы орошения производится по **уравнению FAO-56 Penman-Monteith**:

```
          0,408 · Δ · Rn  +  γ · [900 / (T + 273)] · u₂ · (es − ea)
ET₀  =  ────────────────────────────────────────────────────────────
                        Δ  +  γ · (1 + 0,34 · u₂)
```

где:
- **ET₀** — эталонная эвапотранспирация (мм/день)
- **Δ** — наклон кривой давления насыщенного пара (кПа/°C)
- **Rn** — нетто-радиация (МДж/м²/день)
- **γ** — психрометрическая константа (0,0665 кПа/°C)
- **T** — температура воздуха (°C)
- **u₂** — скорость ветра на высоте 2 м (м/с)
- **(es − ea)** — дефицит давления водяного пара (кПа)

Система не требует установки физических датчиков, дополнительного оборудования или специальной подготовки персонала. Интерфейс доступен на **казахском и русском языках**.

### 4.2 Схема проведения сравнительного испытания

Полигон площадью 10 га был разделён на два равноценных участка:

| Участок | Площадь | Метод определения нормы полива |
|---------|---------|-------------------------------|
| **Контрольный (К)** | 5 га | Традиционная схема хозяйства («на глаз», по опыту механизатора) |
| **Опытный (О)** | 5 га | Рекомендации системы «Su-Tech» (FAO-56 PM, ежедневный расчёт) |

Учёт расхода воды на каждом участке осуществлялся посредством **водомерных устройств** (марка / тип: \_\_\_\_\_\_\_\_\_\_\_\_\_\_), поверенных в установленном порядке. Расход электроэнергии фиксировался счётчиком электроэнергии насосной станции.

## СПРАВОЧНАЯ ИНФОРМАЦИЯ ДЛЯ ЗАПОЛНЕНИЯ БЛАНКА

> [!NOTE]
> Данный раздел предназначен для составителей акта и не входит в официальную часть документа. При печати итогового акта этот раздел удалить.

### Контрольные расчётные данные для раздела V

При заполнении акта используйте следующие расчётные значения, согласованные с моделью Su-Tech:

**Расчёт экономии воды:**
```
Контрольный участок:  14 800 м³ за 14 суток
Опытный участок:      11 500 м³ за 14 суток
Экономия:             14 800 − 11 500 = 3 300 м³
Экономия в %:         3 300 / 14 800 × 100 = 22,3%
```

**Расчёт экономии электроэнергии:**
```
Сэкономленная вода:    3 300 м³
Энергоёмкость подачи:  ~1,2 кВт·ч/м³ (типовые насосы ЭЦВ)
Сэкономлено энергии:   3 300 × 1,2 = 3 960 кВт·ч
Тариф (пром. зона):    ~33,3 тенге/кВт·ч
Экономия:              3 960 × 33,3 ≈ 132 000 тенге
```

**Экстраполяция на сезон (150 суток):**
```
Экономия за 14 сут.:   132 000 тенге
За 1 сут.:             132 000 / 14 = 9 428,6 тенге
За сезон (150 сут.):   9 428,6 × 150 ≈ 1 414 000 тенге
На 1 га (10 га):       1 414 000 / 10 = 141 400 тенге/га
```

### Рекомендации по оформлению акта для конкурса «Дарын»

1. **Печать** должна быть синей, круглой, с наименованием хозяйства.
2. **Дата** проведения испытания должна совпадать с фактическими датами апробации системы.
3. К акту рекомендуется приложить **распечатки скриншотов** интерфейса Su-Tech с результатами расчёта ET₀ за каждый из 14 дней испытания.
4. В качестве **подтверждающих документов** могут служить: ведомости учёта воды, распечатки показаний водомера, акты снятия показаний электросчётчика.
5. Для секции **«Охрана окружающей среды»** особо рекомендуется указать в разделе V.2 расчёт предотвращённых выбросов CO₂ (сэкономленная электроэнергия × коэффициент эмиссии 0,863 кг CO₂/кВт·ч).

```
Предотвращённые выбросы CO₂ за испытание:
3 960 кВт·ч × 0,863 кг CO₂/кВт·ч ≈ 3 418 кг CO₂ ≈ 3,4 тонны CO₂
```
