# Su-Tech Mini App refinement

**Historical record:** the owner subsequently requested the complete pre-unslop design back. The visual changes described below are superseded by [the restoration report](DESIGN_RESTORE_2026-11-18.md); only the verified interaction improvements are retained.

Completed the requested unslop passes on the existing field setup interface, preserving its logo, green identity, section order, calculations, Telegram integration and RU/KZ/EN.

## Skills and direction

Installed and read [unslop](https://github.com/heydamir/unslop/tree/main/skills/unslop), [Impeccable](https://github.com/pbakaus/impeccable/tree/main/.agents/skills/impeccable), [Taste Skill](https://github.com/Leonxlnx/taste-skill/tree/main/skills/taste-skill), and [Motion React](https://github.com/alloc/skills/tree/main/frontend/motion-react).

Direction: calm, precise, practical field planning. The actual satellite map carries the visual detail; the rest uses neutral surfaces and the original green accent. A thin active navigation marker is the signature detail.

Unslop remains the primary brief. Impeccable's Operate guidance and motion checks apply. Taste's marketing-page kit, randomized palettes, full-screen sections and decorative moments conflict with the approved app workflow, so they were not imposed. Its gate reported `GATE: OFF (no build active)`; no Taste gate pass is claimed. Motion principles were applied with CSS and the browser animation API; React and an animation runtime were not added to this plain JavaScript application.

## Nine passes

1. Spacing: consistent 4px rhythm, shared panel/control insets and 44px language targets.
2. Color: removed glass, glows, gradient surfaces/text and colored background washes; retained green selections and primary actions.
3. Icons: removed decorative crop emoji and emoji labels; retained the existing line icon family.
4. Copy: specific irrigation title and factual explanation, localized sentence-case statuses and footer.
5. Type: retained Inter in the precise interface role, reduced heavy type and improved small labels; tabular measurement figures.
6. Layout: actual map and settings side by side on desktop, single reading order on mobile, more compact utility hero.
7. Details: explicit selected states, shared radii, keyboard focus and a skip link. Automatic device/Telegram theme behavior retained.
8. Visuals: actual map remains the product visual. No generated image, invented data, or decorative visual was needed.
9. Motion: 180ms selection continuity and user-opened help, brief control feedback, no ticker/sheens/scroll choreography. Live reduced-motion preference cancels help movement and removes selection movement. Submission stays still.

Removed accumulated decorative CSS layers from `app.css`; replaced `glass.css` with `workspace.css`. Fixed two existing Windows test incompatibilities: dynamic imports use file URLs; result translation parsing accepts CRLF.
