# План: Su-Tech простой для фермера и надёжный для агронома

Цель: обычный фермер за 2 минуты настраивает поле и получает понятный совет, а агроном открывает «Почему так?» и видит каждую формулу, источник и допущение. Простота снаружи, строгость внутри. Ничего не придумывается: где данных нет, бот прямо об этом говорит.

Связанные документы: `docs/AGRONOMY_FIX_PLAN.md` (исправление слабых мест), `docs/METHOD.md`, `docs/COEFFICIENT_CHECK.md`, `docs/AGRONOMIST_BRIEF.md`.

## 1. Принципы (по ним проверяется каждая задача)

1. **Фермер не вводит числа, которых не знает.** Kc, p, EC, глубина корней подставляются из проверенного каталога.
2. **Каждое допущение видно и меняется.** Всё, что бот предположил, показывается списком «Мы предположили…».
3. **Нет метода, нет совета.** Если расчёт не описывает ситуацию, бот не даёт объём и объясняет почему (так уже сделано для субстрата и отапливаемой теплицы).
4. **Каждое число имеет источник.** Строка таблицы FAO или метка «оценка проекта».
5. **Одна формула в трёх местах:** Python, бот, сайт. Расхождение ломает автоматические тесты.
6. **Бот оценивает свою точность сам** по ответам фермера, а не просит верить на слово.

## 2. Что увидит фермер (путь пользователя)

Пять вопросов, остальное по умолчанию:
1. **Где поле:** точка на карте.
2. **Что растёт:** поиск по названию («огурец», «свёкла»), без чисел.
3. **Когда посадили:** дата (не «число дней»).
4. **Как поливаете:** кнопки с картинками (капля, дождевание, арык, борозды).
5. **Насос и тариф:** по желанию, можно пропустить.

Сразу после этого экран **«Мы предположили»**: почва (суглинок), засоления нет, КПД полива, календарь стадий для культуры. Рядом кнопка «Уточнить». Для почвы встроенный тест «скатай шнурок из земли». Фермер не обязан ничего менять, но видит, что менять можно.

Ежедневный совет: одна строка («Сегодня полить: 120 м³, насос около 2 часов, около 3 000 ₸»), под ней «Почему так?» и уровень доверия.

## 3. Каталог культур: один источник правды

**Проблема сейчас:** каждая культура вписана в Python, в JS, в Mini App, в чат-планировщик и в переводы, поэтому добавить культуру трудно и легко ошибиться.

**Решение:** файл `crops/catalog.json`, из которого автоматически собираются всё остальное.

Поля культуры: названия на трёх языках; группа; Kc (нач / сер / кон); стадии в днях (вариант для засушливого климата); минимальная и максимальная глубина корней; p; высота (для поправки на климат); порог солёности ECe и наклон b; **источник** (таблица и строка FAO-56 / FAO-29) и **статус** (`FAO-56` или `оценка проекта`).

Что собирается автоматически: `bot/water_balance.py` (CROPS), `balance.js` (CROPS), список культур с поиском в Mini App и в боте, подписи на трёх языках, документ `COEFFICIENT_CHECK.md`.

Состав: сначала 25–30 культур, которые реально растут в Казахстане (по таблицам 11, 12, 22, 23 FAO-56): пшеница, ячмень, кукуруза, рис, хлопок, сахарная свёкла, подсолнечник, картофель, томат, огурец, перец, баклажан, капуста, лук, морковь, арбуз, дыня, тыква, люцерна, фасоль, горох, клубника, виноград и яблоня (многолетние отдельным этапом).

**Проверки (автотесты):**
- каждая строка каталога заполнена, источник указан;
- числа в допустимых диапазонах (Kc 0,1–1,5; p 0,1–0,8 и т. д.);
- генерация Python и JS даёт одинаковые числа на всех культурах и днях;
- ручной эталонный расчёт для 5 культур из книги.

**Риск:** числа из книги нужно переносить аккуратно. Поэтому первая версия каталога собирается **скриптом из скачанного текста FAO-56** (как сегодня при сверке), а не вручную, и результат проверяется глазами по таблицам.

## 4. Засоление без лаборатории

Три простых вопроса про то, что фермер видит:
- есть ли на земле белая корка или белые пятна: нет / местами / много;
- встают ли всходы пятнами или плохо по краям поля;
- откуда вода: река / канал / скважина.

Ответы дают **уровень: нет / слабое / среднее / сильное**. Каждому уровню соответствует диапазон ECe, расчёт использует осторожное значение с пометкой «примерно». Границы классов (по USDA около 2, 4, 8, 16 дСм/м) **нужно подтвердить по источнику**: сайт USDA пока недоступен из рабочей среды.

Вода: типичной солёности реки или скважины бот **не придумывает**. Предлагает карманный солемер (в стакан воды, прочитать число) или лабораторный анализ. Пока числа нет, объём не меняется, но видно предупреждение.

Сильное засоление или «слишком солёная вода» → совет не выдаётся, только «нужен агроном» (так уже работает).

Лабораторные ECw и ECe остаются как необязательный «точный режим».

## 5. Уровень доверия у каждого совета

Три уровня, считаются автоматически:
- **Высокий:** культура и стадии из FAO-56, фермер за последние 7 дней подтверждал влажность, почва определена тестом, есть ECw при засолении.
- **Средний:** есть предположения (почва по умолчанию, давно не было проверки, культура с меткой «оценка проекта»).
- **Низкий / нужен агроном:** сильное засоление, метод на границе применимости, большой разрыв между советом и ответами фермера.

Рядом с уровнем одна фраза, **что поднимет его**: «подтвердите влажность почвы» или «укажите дату посадки».

## 6. Карточка «Почему так?» (то, что впечатлит агронома)

Нажать можно у любого совета. Показывает на языке фермера, а ниже, развернуто, для агронома:
1. Исходные данные: погода (ET₀, дождь, источник), культура и день, стадия.
2. Формулы с числами: TAW, RAW, ETc, дефицит, объём, насос, как в демо.
3. Источник каждого коэффициента и метка «FAO-56» / «оценка проекта».
4. Что было предположено.
5. **Чувствительность:** «если реальный расход на 15% выше, объём изменится на столько-то» и «если почва держит на 20% меньше, полив нужен на N дней раньше». Это прямой ответ на вопрос агронома «а если вы ошиблись?».
6. История: что было вчера, позавчера, что фермер отмечал.

Эта же карточка выгружается **файлом (CSV/PDF)** для агронома: поле, параметры, расчёт по дням.

## 7. Режим агронома

Кнопка «Режим эксперта» (включается самим фермером или по ссылке агронома):
- можно изменить Kc, p, глубину корней, стадии, почву, КПД;
- любое изменение помечается «изменено вручную» с записью кто и когда;
- расчёт идёт по изменённым значениям, а подсказка показывает, чем они отличаются от FAO.

Для агронома это означает: бот не чёрный ящик, он подчиняется специалисту.

## 8. Самопроверка и подстройка по полю

Каждую неделю фермер отвечает «влажная / нормальная / сухая». Бот сравнивает ответ со своим расчётом и **копит ошибку по этому полю**:
- показывает на карточке поля: «За последние 4 проверки бот ошибся на N%»;
- если ошибка устойчиво в одну сторону, предлагает поправку (например, «растения расходуют больше, чем в таблице») и применяет её **только после подтверждения** фермером или агрономом, с пометкой «подстроено по полю»;
- эти данные годятся для опыта и пилота: готовая выгрузка «расчёт против факта».

Честно: пока нет данных пилота, поправка не включается сама. Сначала сбор статистики и показ.

## 9. Напоминания

Если платформа умеет сообщения по расписанию, утреннее сообщение со сводкой по полям и просьбой о проверке влажности раз в неделю. Нужно сначала проверить возможности Telegram Serverless; если нет, прямо сказать и обойтись кнопкой «Мои поля».

## 10. Надёжность и тесты (чтобы «хорошо работало»)

- **Тесты каталога** (раздел 3), **тест «Python = JS»** на 5 000 случайных полей с любой культурой из каталога.
- **Эталонные случаи**, рассчитанные вручную по книге, для 10 разных ситуаций (теплица, засоление, капля, арык, рис).
- **Сценарные тесты бота:** новое поле за 5 вопросов на всех трёх языках; «нет метода, нет совета»; уровень доверия меняется от ответов.
- **Проверка перед выкладкой уже есть:** бот обновляется только после зелёных тестов, а ночная копия сохраняет живой код.
- **Откат:** каждое изменение это отдельный коммит; откат одним коммитом.
- **Ночной контроль:** раз в сутки запускается набор эталонных расчётов на живом боте и сравнивается с ожидаемыми числами.

## 11. Как измерить, что получилось

- Время настройки поля: цель не больше 2 минут для новичка (замерить на 3–5 людях).
- Доля полей с уровнем доверия «высокий» после первой недели.
- Ошибка бота по недельным проверкам: цель в среднем не больше одной ступени «влажная / нормальная / сухая».
- Что говорит агроном после просмотра карточки «Почему так?»: записать вопросы, на которые бот не ответил.

## 12. Этапы и оценка времени

| Этап | Что | Оценка |
|---|---|---|
| A | Каталог культур из FAO-56, генерация в Python, бот и сайт, поиск, тесты | 5–6 ч |
| B | Путь «5 вопросов», экран «Мы предположили», тест «шнурок» | 3–4 ч |
| C | Засоление по признакам, подтверждение границ классов по источнику | 2–3 ч |
| D | Уровень доверия и карточка «Почему так?» с чувствительностью, выгрузка | 4–5 ч |
| E | Режим агронома | 3 ч |
| F | Самопроверка по недельным ответам, показ ошибки, выгрузка | 3–4 ч |
| G | Напоминания (после проверки платформы) | 1–2 ч |
| H | Пересчёт исследования, обновление сайта, презентации и справки | 2–3 ч |

Всего около 25–30 часов моей работы. За один день реально A, B, C и половина D; полностью план закрывается за 3–4 рабочих дня при условии, что ты проверяешь бота на телефоне после каждого этапа.

## 13. Что нужно от владельца

- Проверять результат на телефоне после каждого этапа (я напишу, на что смотреть).
- Найти хотя бы одного агронома для просмотра карточки «Почему так?» и списка культур (шаг после этапа D).
- Ответ хозяина теплицы или другого фермера по пяти вопросам настройки (этапы B и F) — чтобы проверить, что путь действительно понятен.
- Решить, какие культуры нужны первыми, если не все 25–30.

## 14. Известные риски

| Риск | Что делаем |
|---|---|
| Ошибки при переносе таблиц | Каталог собирается скриптом из текста FAO-56 и проверяется глазами; тесты на диапазоны |
| Границы классов засоления и тексты проверки почвы (USDA) не подтверждены | Пометка «примерно»; проверка агрономом; не выдаются как норма |
| Каталог сломает старые сохранённые поля | Миграция: старые ключи культур остаются, тест на чтение старых полей |
| Слишком много текста в «Почему так?» | Два уровня: коротко для фермера, развёрнуто по кнопке |
| Подстройка по полю усилит ошибку фермера | Включается только вручную, с пометкой и откатом |
| Платформа не умеет напоминания | Честно сказать и оставить ручной путь |

## 15. Что НЕ обещаем в этом плане

Сады и виноград (многолетние, отдельная логика), капельная зона смачивания в запасе воды (в FAO-56 нет правила), метод дождя по почве без источника, фертигация, управление насосом (автоматика остаётся прототипом).
