# Метод расчёта Su-Tech (версия движка fao56.9)

Документ для агронома: что именно считает бот, по каким формулам, откуда числа и что **не проверено**. Код: `bot/water_balance.py` (Python, на нём считается исследование) и `serverless/tgcloud/lib/balance.js` (живой бот; сайт использует его точную копию `sutech-frontend/js/sutech-engine.js`). Совпадение Python и JS проверяется тестом по 675 эталонным сценариям (`serverless/test/balance-fixtures.json`, создаётся `serverless/generate-reference.py`) и независимым пересчётом по определениям FAO-56 на 5 000 случайных полях (`serverless/test/independent-audit.test.js`).

## Метка проверки источников

- **[проверено]** значение сверено с текстом FAO-56 на fao.org 17.11.2026. Подробная сверка: `docs/COEFFICIENT_CHECK.md`.
- **[проект]** значение выбрано проектом, в книге такого числа нет.
- **[не сверено]** ещё не сверено с книгой.

Сверены таблицы 11, 12, 19, 20 и 22 FAO-56. В ходе сверки исправлены θFC/θWP суглинка и глины и начальный Kc дыни.

## 1. Что считается каждый день

Для поля с культурой, почвой, способом полива и днём от посадки:

1. **ET₀** (мм/сутки) и осадки берутся из прогноза Open-Meteo (`et0_fao_evapotranspiration`, `precipitation_sum`) на местный день поля. Пропущенные дни за последние 30 дней досчитываются по тем же данным.
2. **Kc и глубина корней** по календарю культуры: четыре стадии (начало, развитие, середина, конец) с линейным переходом Kc между ними (FAO-56, ур. 66). Глубина корней растёт линейно от минимума к максимуму за первые две стадии. **Для капельного и подпочвенного полива** начальный Kc умножается на долю смоченной поверхности fw = 0,35 (FAO-56, табл. 20 и ур. 60); для остальных способов без изменения. [проверено]
3. **Запас воды у корней** (FAO-56, ур. 82–83):
   - TAW = 1000·(θFC − θWP)·Zr, мм;
   - RAW = p·TAW, мм.
4. **Коэффициент стресса** Ks (ур. 84): равен 1, пока дефицит не превышает RAW; затем (TAW − Dr)/((1 − p)·TAW).
5. **ETc** = Ks·Kc·ET₀.
6. **Эффективный дождь** — правило проекта, не FAO: осадки меньше 5 мм не учитываются, при 5 мм и более учитывается 75% (85% для риса). [не сверено; метод будет заменён, шаг 2.3]
7. **Дефицит на конец дня** Dr = ограничен [0, TAW]: Dr_вчера + ETc − Peff (ур. 85 без стока и капиллярного подъёма).
8. **Решение:**
   - дефицит больше RAW — `critical` («поливать сейчас»);
   - иначе дефицит не меньше порога полива — `irrigate`;
   - иначе `deferred` («можно не поливать»).
   - Порог полива = min(порог технологии, RAW). Порог технологии: капля и подпочвенный 5 мм, дождевание и пивот 20 мм, арык 40 мм. [проект, не FAO]
9. **Объём брутто** = дефицит·10·площадь(га) ÷ КПД. КПД: капля 0,90, дождевание и пивот 0,75, арык 0,50. [проект]
10. **Засоление (только если введены результаты анализа):** по ECw добавляется вода для промывки солей (FAO-29, ур. 9: LR = ECw / (5·ECe_порог − ECw); объём делится на min(КПД, 1 − LR)); по ECe показывается ожидаемая потеря урожая b·(ECe − порог) % (FAO-56, табл. 23). Без анализа ничего не считается. [проверено]
11. **Насос:** часы = объём ÷ производительность; стоимость = часы·мощность·тариф. Если объём больше, чем насос подаёт за 20 часов в сутки (`PUMP_MAX_HOURS_PER_DAY`), бот советует разделить полив на нужное число дней (добавлено в шаге 1.1 плана).

Вес вчерашнего дефицита при первом расчёте задаёт фермер словами: «недавно полито» = 0, «нормальная» = 0,5·RAW, «сухая» = RAW.

## 2. Параметры

**Почвы** (θFC, θWP, м³/м³) [проверено, табл. 19, середины диапазонов]: песок 0,12/0,05; суглинок 0,25/0,10; глина 0,36/0,21. Доступная вода у суглинка и глины одинакова (0,15); в книге у этих классов диапазоны доступной воды почти совпадают (0,13–0,18 и 0,12–0,20).

**Культуры** (p, максимальная глубина корней, Kc: [проверено], табл. 12 и 22; минимальная глубина корней [проект]; стадии: хлопок, картофель, дыня, люцерна [проверено], табл. 11; пшеница, кукуруза, томат [проект], отличаются от книги, см. `COEFFICIENT_CHECK.md`):

| Хлопок | 0,65 | 0,25–1,35 | 0,35 / 1,18 / 0,65 | 30, 50, 60, 55 |

Рис считается отдельно: слой воды 10–15 см плюс фильтрация (глина 3, суглинок 6, песок 12 мм/сутки), Kc = 1,25, КПД 0,50. Культура «другая»: фермер вводит Kc, глубину корней и p.

**Теплица:** осадки равны нулю; ET₀ = уличная ET₀ × 0,70 (допущение о светопропускании плёнки) или значение, введённое фермером [проект, не проверено]. Для субстрата и для отапливаемой теплицы без измеренного ET₀ совет не выдаётся (причина показывается).

## 3. Чего метод сейчас НЕ делает (известные пробелы)

Каждый пункт разобран в `docs/AGRONOMY_FIX_PLAN.md` с номером шага:

- Не считает запас воды капли только для смоченного объёма: в FAO-56 такого правила нет (1.2, отложено до источника). Поправка Kc ini на fw уже учтена.
- Засоление учитывается только при введённых ECw и ECe (1.3 сделано); влияние соли на испарение (Ks) не моделируется; вход ECw/ECe есть в Mini App, в чате бота пока нет.
- Теплица: допущение 0,70 для неотапливаемой теплицы не проверено в теплицах; калибровки по фактическому расходу воды нет (после пилота).
- Нет поправки Kc на сухой ветреный климат (FAO-56, ур. 62) и поправки порога p на ETc (2.1, 2.2).
- Дождь учитывается скачком на 5 мм без учёта почвы (2.3).
- Три почвы; глина совпадает с суглинком (2.4).
- Состояние почвы вводится на глаз тремя словами (2.5).
- Нет сахарной свёклы, огурца, перца, лука, сада (2.6).
- Погода из сеточной модели, без поправки на оазис (2.7).
- Арык: бот не знает очередь воды (3.1). Нет осознанного недолива (3.2).
- Показатели исследования (15–28%) получены в симуляции, где «реальное поле» считается той же моделью (4.2).

## 4. Как проверить расчёт самому

```bash
python3 run_tests.py                      # Python-тесты
cd serverless && node --experimental-loader ./test/sdk-loader.mjs --test test/*.test.js
python3 serverless/generate-reference.py # заново создать эталоны из Python
```

Пример для ручной проверки: пшеница, суглинок, капля, 1 га, 60-й день, почва «сухая», ET₀ 5 мм, дождя нет. TAW = 1000·(0,33 − 0,18)·1,25 = 187,5 мм; RAW = 0,55·187,5 = 103,125 мм; Kc на 60-й день = 1,15; ETc = 5,75 мм; дефицит = 103,125 + 5,75 = 108,875 мм (больше RAW — «поливать сейчас»); объём = 108,875·10 ÷ 0,90 = 1 209,7 м³.
