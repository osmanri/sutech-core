# Как всем этим пользоваться (простыми словами)

## Кто что делает

| Ты | Claude (я) |
|---|---|
| Пишешь, что нужно: «поменяй текст», «добавь кнопку», «сделай слайд» | Меняю код или презентацию |
| Смотришь результат и говоришь «ок» или «не так» | Запускаю тесты, делаю коммит и пуш |
| Раз в жизни положил ключи в GitHub (уже сделано) | Сливаю в `main`; GitHub сам обновляет бота |

Ты **ничего не копируешь и не запускаешь**. Просто пишешь запрос в чат.

## Что происходит после твоего запроса

1. Я меняю файлы и прогоняю проверки (бот: 729, Python: 316, сайт: 8).
2. Я сам делаю коммит и пуш в ветку `claude/project-competition-review-f8o9yv`.
3. Я сам открываю «запрос на слияние» и вливаю его в `main`.
4. Если менялся бот (`serverless/`, `bot/`), GitHub **сам** прогоняет проверки и обновляет бота в Telegram (Actions → `deploy-bot`).
5. Я проверяю, что зелёная галочка, и пишу тебе.

## Кнопки на GitHub (вкладка Actions), если когда-нибудь понадобятся

| Название | Что делает | Опасно? |
|---|---|---|
| `deploy-bot` | выложить бота | нет, сначала тесты |
| `compare-bot` | показать, чем живой бот отличается от кода | нет, ничего не меняет |
| `backup-live-bot` | сохранить живой код в ветку `live-bot-backup`, если он отличается от `main` (раз в сутки само) | нет |
| `pull-live-bot` | разовый снимок живого кода (уже использован) | нет |

## Демо

- В боте: «Ещё» → «Демо для жюри» (на главном экране кнопки нет).
- Ссылка из QR: `https://t.me/Su_Tech_bot?start=demo_ru` (`demo_kz`, `demo_en` для других языков).
- Показывает фиксированный расчёт (пшеница, 1 га, суглинок, капельный полив, 60-й день), ничего не сохраняет, интернет не нужен.

## Если что-то сломалось

1. Actions → последний запуск → красный → открыть, пришли мне скриншот или текст ошибки.
2. Бот не отвечает после выкладки: напиши мне. Предыдущая версия есть в истории GitHub, откат делается одним коммитом.

## Что нельзя / нельзя делать без согласования

- Не править код бота прямо в панели Telegram Cloud и не выкладывать с компьютера в обход GitHub: тогда живой бот разойдётся с репозиторием. Если так вышло, `backup-live-bot` сохранит живой код в ветку, и я слью.
- Ключ `BOT_ENV` лежит в Settings → Secrets → Actions. Никому не отправляй.
- Mini App (сайт внутри Telegram) в автовыкладку **не входит**. Пока он обновляется отдельно.
